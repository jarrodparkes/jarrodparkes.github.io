# JarrodParkes.com

This is the repository for [https://jarrodparkes.github.io/](https://jarrodparkes.github.io/). It uses the [vida jekyll theme](https://github.com/syaning/vida).

## Testing Locally

```bash
brew install rbenv
rbenv install 3.4.9
rbenv local 3.4.9
gem install jekyll
rbenv rehash
jekyll serve
```
